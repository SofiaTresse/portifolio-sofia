# Portfólio — Sofia Tresse

Site estático em amarelo manteiga e rosa bebê, pronto para GitHub Pages. Não precisa de instalação nem compilação.

## Ver o site

Abra `index.html` no navegador. As fontes são carregadas pelo Google Fonts quando houver internet; há fontes alternativas disponíveis automaticamente.

## Publicar no GitHub Pages

1. Crie um repositório no GitHub. Para uma página de projeto, pode chamá-lo `portfolio`. Para usar a página principal do seu perfil, o repositório deve se chamar exatamente `sofiatresse.github.io`.
2. Envie **o conteúdo desta pasta** para a raiz do repositório: `index.html`, `styles.css`, `script.js`, `.nojekyll` e a pasta `assets`. O arquivo `index.html` deve ficar diretamente na raiz, sem uma pasta extra ao redor.
3. No repositório, abra **Settings → Pages**.
4. Em **Build and deployment**, escolha **Deploy from a branch**.
5. Selecione a branch `main`, a pasta `/ (root)` e clique em **Save**.
6. Aguarde a publicação. Se o repositório se chamar `portfolio`, o endereço será `https://sofiatresse.github.io/portfolio/`. Para `sofiatresse.github.io`, será `https://sofiatresse.github.io/`.

Todos os caminhos de arquivos são relativos, compatíveis com as duas opções.
